# Laura Feiteira Aesthetics Platform

Professional web platform for Laura Feiteira Estética, an aesthetics clinic.

## Project Overview

This platform includes a public website, client area, booking system, payment flow, automated emails, Google reviews integration, and an owner dashboard for managing appointments, services, prices, promotions, availability, and analytics.

## Tech Stack

### Frontend

- React
- TypeScript
- Tailwind CSS
- Vite

### Backend

- Node.js
- Fastify
- TypeScript
- PostgreSQL
- Prisma
- JWT Authentication
- Google OAuth
- Nodemailer

### Infrastructure

- Frontend: Vercel
- Database: Neon PostgreSQL
- Backend primary: Railway
- Backend failover: Render
